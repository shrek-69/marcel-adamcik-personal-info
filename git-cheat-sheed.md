# My Git Command Cheat Sheet

## git clone
Creates a local copy of an existing remote repository.

Example: `git clone https://github.com/username/repository.git`

## git status
Displays the current status of the working directory and staging area. It shows untracked, modified and staged files.

Example: `git status`

## git add
Adds the current changes of a file to the staging area and prepares them for the next commit.

Example: `git add index.html`

## git commit
Saves staged changes in the local repository with a commit message.

Example: `git commit -m "Add personal information page"`

## git log
Displays the commit history of the repository.

Example: `git log --oneline`

## git push
Uploads local commits to the remote repository.

Example: `git push`

## git pull
Downloads changes from the remote repository and integrates them into the current local branch.

Example: `git pull`
